# Oathon v0.1 normative test vectors

Conformance suite for CRYPTOGRAPHY.md §15. Generated by
`ops/generate_vectors.py`; verified independently by
`packages/sdk-python/tests/test_vectors.py` and `test_schemas.py`.

- **keys.json** — INSECURE DETERMINISTIC TEST KEYS. Seeds are public by
  design (seed = SHA-256 of `WARRANT-INSECURE-TEST-KEY:<label>`) so any
  implementation can re-sign and compare bytes. Never use these keys for
  anything but tests.
- **vectors.json** — 21 known-answer cases: signatures (valid, field-mutated,
  metadata-mutated, wrong key), key genesis/transition, writer authorization
  (valid + mismatch), event hashes (genesis, chained, Unicode), chains
  (valid, event mutation, predecessor mutation), digest helpers, segment
  close (valid + wrong authorization), anchor input, and the per-writer
  segment-close chain (valid + broken link).
- **schema-cases.json** — 46 validation cases as raw JSON text, including
  parse-level rules (duplicate keys, NaN, ±Infinity) that cannot be
  represented as parsed JSON.

Ed25519 is deterministic: `signature_value` fields are exact expected bytes,
not merely "a valid signature".
